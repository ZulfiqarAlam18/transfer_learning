🎓 GETTING WHATSAPP CREDENTIALS:

1. Go to: https://developers.facebook.com/
2. Create a new app (or use existing)
3. Add "WhatsApp" product
4. Navigate to: WhatsApp → API Setup
5. Copy these values:
   - Temporary Access Token → WHATSAPP_TOKEN
   - Phone Number ID → PHONE_NUMBER_ID
6. For production, create permanent token in Business Settings

🐛 TROUBLESHOOTING:

Issue: npm install fails
  → Ensure Node.js 18+ is installed
  → Run: node --version

Issue: Webhook verification fails
  → Check verify token matches in .env and Meta Console
  → Ensure server is publicly accessible

Issue: Messages not received
  → Verify webhook is configured correctly
  → Check "messages" field is subscribed
  → Review server logs for errors

Issue: Can't remove users from group
  → Bot must be admin in the WhatsApp group
  → Verify group ID is being sent in webhook

Issue: Admin commands don't work
  → Check phone number format (no + sign)
  → Example: 15551234567 not +1-555-123-4567
  → Restart server after changing .env

More help: See DEPLOYMENT.md troubleshooting section
